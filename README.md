# numerical-methods-gui
Numerical Methods GUI Calculator
We aim to design and develop an interactive Graphical User Interface (GUI) for an advanced calculator that enables users to input problems and select the appropriate numerical method from key methods covered in the Numerical Methods course, while displaying final results with suitable precision, showing solution steps, and checking convergence conditions
Implemented Methods (Part 1)
- Root-Finding Methods: Bisection, False Position, Newton-Raphson, Secant, Fixed Point
- Linear Systems Methods: Gauss Elimination, Doolittle LU Decomposition, Thomas Algorithm, Jacobi, Gauss-Seidel
